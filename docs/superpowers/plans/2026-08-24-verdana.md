# Fonte padrão Verdana — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar a fonte padrão do editor de provas de Liberation Sans para Verdana nos três caminhos (editor, PDF, DOCX), eliminando a marca `fontFamily` fossilizada no modelo.

**Architecture:** A fonte passa a viver exclusivamente no CSS (`.ed-root`), nunca no modelo Y.js. Um helper novo no `@sofereditor/core` limpa as marcas `fontFamily` existentes na abertura do documento; o `forceArialOnImport` que as criava é removido. O servidor passa a embutir as duas famílias (Liberation Sans para snapshots antigos, Verdana para os novos), então prova antiga em formato legado renderiza byte-idêntica.

**Tech Stack:** TypeScript, Y.js, React, vitest (monorepo), NestJS + Jest + Puppeteer (api-portal), Next.js 14 e Vite (frontends), pnpm workspaces.

**Spec:** `docs/superpowers/specs/2026-08-24-verdana-design.md`

```ts
/**
 * Migrações de modelo — transformações one-shot sobre um documento existente.
 *
 * Regra do projeto: a fonte do editor mora no CSS (`.ed-root`), nunca no
 * modelo. Fonte inline fossiliza o documento e transforma "trocar a fonte"
 * numa migração de dados, que foi exatamente o que aconteceu com o
 * `forceArialOnImport` dos apps consumidores.
 */
import * as Y from "yjs";
import type { EditorDocument } from "./document";
import type { DeltaOp } from "./types";

/** Trecho contíguo de um `Y.Text` que carrega a marca. */
interface Alvo {
  yText: Y.Text;
  ranges: Array<[index: number, length: number]>;
}

function coletar(yText: Y.Text | undefined, alvos: Alvo[]): number {
  if (!yText) return 0;
  const delta = yText.toDelta() as DeltaOp[];
  const ranges: Array<[number, number]> = [];
  let index = 0;
  for (const op of delta) {
    // Embeds (imagem, fórmula) têm length 1 e nunca receberam a marca —
    // `forceArialOnImport` pulava insert não-string.
    const len = typeof op.insert === "string" ? op.insert.length : 1;
    if (typeof op.insert === "string" && op.attributes && "fontFamily" in op.attributes) {
      ranges.push([index, len]);
    }
    index += len;
  }
  if (ranges.length > 0) alvos.push({ yText, ranges });
  return ranges.length;
}

/**
 * Remove toda marca `fontFamily` do documento — de blocos e de células de
 * tabela. Remove **todas**, não só as de valor conhecido: com o dropdown de
 * fonte fora da toolbar, nenhuma marca legítima pode existir.
 *
 * Idempotente e observável: conta antes de escrever e só abre transação se
 * houver o que limpar. Documento já migrado não gera update no Y.Doc, logo não
 * dispara o autosave e não regrava o `htmlSnapshot`.
 *
 * A transação usa origin `"migration"`, seguindo a convenção de `"pageSettings"`
 * e `"import"` (`document.ts:106`) — origens que o `UndoManager` não rastreia.
 * Sem isso, o primeiro Ctrl+Z do professor desfaria a migração em vez da edição
 * dele.
 *
 * @returns número de runs que carregavam a marca. 0 = nenhuma escrita.
 */
export function stripFontFamilyMarks(
  doc: EditorDocument,
  opts?: { dryRun?: boolean },
): number {
  const alvos: Alvo[] = [];
  let total = 0;

  for (let i = 0; i < doc.blockCount(); i++) {
    total += coletar(doc.getBlockText(i), alvos);
    const cells = doc.getCells(i);
    if (cells) {
      for (let c = 0; c < cells.length; c++) {
        total += coletar(doc.getCellText(i, c), alvos);
      }
    }
  }

  if (total === 0 || opts?.dryRun) return total;

  doc.ydoc.transact(() => {
    for (const { yText, ranges } of alvos) {
      for (const [index, length] of ranges) {
        yText.format(index, length, { fontFamily: null });
      }
    }
  }, "migration");

  return total;
}
```

```ts
// ─── @font-face embutido em base64 ────────────────────────────────────────
//
// Usado APENAS no backend. Garante que o Chromium do Puppeteer renderize com a
// fonte certa em vez de cair em fallback (DejaVu) em servidores Linux —
// fallback gera métricas diferentes e desloca quebras de página.
//
// As DUAS famílias coexistem de propósito:
//   - Verdana: fonte atual, nomeada pelos snapshots novos.
//   - Liberation Sans: fonte anterior (06/2026–08/2026), nomeada pelo CSS que
//     os snapshots ANTIGOS carregam inlinado. Remover quebraria toda prova
//     antiga, que passaria a repaginar num PDF já impresso e entregue.

interface FaceSpec {
  family: string;
  file: string;
  weight: 400 | 700;
  style: 'normal' | 'italic';
  fmt: 'truetype' | 'woff2';
}

const FACES: FaceSpec[] = [
  { family: 'Liberation Sans', file: 'LiberationSans-Regular.ttf', weight: 400, style: 'normal', fmt: 'truetype' },
  { family: 'Liberation Sans', file: 'LiberationSans-Bold.ttf', weight: 700, style: 'normal', fmt: 'truetype' },
  { family: 'Liberation Sans', file: 'LiberationSans-Italic.ttf', weight: 400, style: 'italic', fmt: 'truetype' },
  { family: 'Liberation Sans', file: 'LiberationSans-BoldItalic.ttf', weight: 700, style: 'italic', fmt: 'truetype' },
  { family: 'Verdana', file: 'Verdana-Regular.woff2', weight: 400, style: 'normal', fmt: 'woff2' },
  { family: 'Verdana', file: 'Verdana-Bold.woff2', weight: 700, style: 'normal', fmt: 'woff2' },
  { family: 'Verdana', file: 'Verdana-Italic.woff2', weight: 400, style: 'italic', fmt: 'woff2' },
  { family: 'Verdana', file: 'Verdana-BoldItalic.woff2', weight: 700, style: 'italic', fmt: 'woff2' },
];

const FMT_MIME: Record<FaceSpec['fmt'], string> = {
  truetype: 'font/ttf',
  woff2: 'font/woff2',
};

let fontFaceCSSCache: string | null = null;

export function getFontFaceCSS(): string {
  if (fontFaceCSSCache !== null) return fontFaceCSSCache;

  const fontsDir = fs.existsSync(path.resolve(__dirname, 'assets/fonts'))
    ? path.resolve(__dirname, 'assets/fonts')
    : path.resolve(process.cwd(), 'src/prova-documento/assets/fonts');

  const faltando: string[] = [];
  const blocos: string[] = [];

  for (const f of FACES) {
    const full = path.join(fontsDir, f.file);
    if (!fs.existsSync(full)) {
      faltando.push(f.file);
      continue;
    }
    const b64 = fs.readFileSync(full).toString('base64');
    blocos.push(`
    @font-face {
      font-family: '${f.family}';
      font-weight: ${f.weight};
      font-style: ${f.style};
      src: url(data:${FMT_MIME[f.fmt]};base64,${b64}) format('${f.fmt}');
    }`);
  }

  // Sem fallback, por decisão do projeto: PDF com métrica errada, impresso e
  // entregue, é pior que PDF ausente. Face faltando = quebra de página no
  // lugar errado, em silêncio.
  if (faltando.length > 0) {
    throw new Error(
      `[shared-print-styles] fontes ausentes em ${fontsDir}: ${faltando.join(', ')}. ` +
        `O PDF renderizaria com fallback e métrica errada. Confira se o build copia **/*.ttf e **/*.woff2 para o dist.`,
    );
  }

  fontFaceCSSCache = blocos.join('\n');
  return fontFaceCSSCache;
}
```

> **Mudança de comportamento deliberada:** antes, arquivo ausente fazia a função devolver string vazia em silêncio e o PDF saía com fallback. Agora **lança**. Isso implementa a regra do projeto ("o PDF do servidor não tem fallback"). Se o usuário preferir manter o comportamento silencioso, este é o ponto a reverter — e só este.
